# オセロゲーム

ブラウザで遊べる本格オセロゲームです。  
サーバー不要・インストール不要で、`index.html` をブラウザで開くだけですぐに遊べます。

---

## 📸 概要

HTML・CSS・JavaScript のみで作られたオセロゲームです。  
2人対戦はもちろん、3段階の強さから選べる CPU 対戦にも対応しています。  
対戦結果はブラウザに自動保存され、勝率などの戦績を確認できます。  
スマートフォンでも快適に遊べるよう、レスポンシブ対応済みです。

---

## ✅ 主な機能

| 機能 | 説明 |
|------|------|
| 2人対戦 | 同じ端末で2人が交互に操作して対戦できます |
| CPU対戦 | 初級・中級・上級の3段階から強さを選んで対戦できます |
| CPU代理 | 2人対戦中に「CPUに任せる」ボタンで1手だけCPUに代わりに打たせられます |
| 戦績管理 | 対戦結果を自動保存し、勝率・対戦履歴を確認できます |
| 設定 | CPU思考時間・ヒント表示・アニメーション・効果音をカスタマイズできます |
| 効果音 | 石を置く・ひっくり返す・ゲーム終了の3種類の効果音が鳴ります（ON/OFF可） |
| 遊び方説明 | ルールや操作方法をモーダルで確認できます |
| スマホ対応 | 画面サイズに応じて盤面・ボタンが自動調整されます |

## 🎮 遊び方

### 基本ルール

1. 黒が先攻でゲームが始まります
2. 相手の石を自分の石で **縦・横・斜め** に挟むと、挟まれた石が自分の色に変わります
3. 石を挟める場所にしか置けません（薄く光るマスが置ける場所です）
4. 置ける場所がない場合は自動でパスになります
5. 両方とも置けなくなったらゲーム終了です
6. 石が多い方の勝ちです（同数は引き分け）

### 起動方法

```
index.html をダブルクリックしてブラウザで開くだけです。
サーバーやインストールは不要です。
```

ローカルサーバーを使う場合（任意）：

```bash
# Python 3 の場合
python -m http.server 8000

# Node.js の場合（npx が使える環境）
npx serve .
```

## 🆚 対戦モード

### 2人対戦

同じ端末で2人が交互に操作します。  
黒・白どちらも人間が担当します。

### CPU対戦

あなたが黒（先攻）、CPU が白（後攻）で対戦します。  
ゲーム開始前に CPU の強さを選べます。

---

## 🤖 CPU の強さ

| レベル | 戦略 | 難易度 |
|--------|------|--------|
| 初級 | 置ける場所の中からランダムに選ぶ | ★☆☆ |
| 中級 | 一番多くの石をひっくり返せる場所を選ぶ（貪欲法） | ★★☆ |
| 上級 | 角・辺を優先し、危険なマスを避けて置く（評価関数） | ★★★ |

**上級 CPU の評価基準：**
- 角（4隅）：+100点（絶対にひっくり返されない最強の場所）
- 角の隣（危険マス）：-30点（相手に角を取られやすくなる）
- 辺（端の行・列）：+10点（比較的安全な場所）
- ひっくり返せる石数：1個につき +1点

## 🤝 CPUに任せる機能

2人対戦中に表示される「🤖 CPUに任せる」ボタンを押すと、  
現在のターンの **1手だけ** CPU（中級）が代わりに打ちます。

- 迷ったときや、相手がいないときの補助として使えます
- CPU が打った後は、次のプレイヤーのターンに戻ります

## ⚙️ 設定

モード選択画面・ゲーム画面どちらの「⚙️ 設定」ボタンからでも設定モーダルを開けます。  
設定内容はブラウザの localStorage に自動保存され、次回起動時も引き継がれます。

| 設定項目 | 選択肢 | 説明 |
|---------|--------|------|
| CPU思考時間 | 短い（300ms） / 普通（500ms） / 長い（1000ms） | CPUが手を打つまでの待機時間を変更します |
| ヒント表示 | ON / OFF | 置ける場所を薄く光らせるハイライトの表示・非表示を切り替えます。OFFでも置けるマスはクリック可能です |
| アニメーション | ON / OFF | 石を置いたときのアニメーション効果の有無を切り替えます |
| 効果音 | ON / OFF | 石を置く・ひっくり返す・ゲーム終了時の効果音の有無を切り替えます |

> **注意：** 設定はブラウザの localStorage に保存されます。  
> 別のブラウザや端末では共有されません。

---

## 🔊 効果音

Web Audio API を使って外部ファイルなしで効果音を生成しています。

| タイミング | 音の種類 |
|-----------|---------|
| 石を置いたとき | 短い「ポン」という音（600Hz → 300Hz） |
| 石をひっくり返したとき | 柔らかい「パタ」という音（400Hz → 200Hz） |
| ゲーム終了時 | ド・ミ・ソの短いファンファーレ |

設定画面で効果音を OFF にすると、すべての効果音が無効になります。  
初期配置・リセット・設定変更などのタイミングでは効果音は鳴りません。

## 📊 戦績管理

ゲーム終了時に対戦結果が自動でブラウザに保存されます。  
「📊 戦績」ボタンから以下を確認できます。

| 表示項目 | 内容 |
|---------|------|
| 対戦数 | 総対戦回数 |
| 勝ち数 | CPU対戦では「あなたの勝ち」、2人対戦では「黒の勝ち」 |
| 負け数 | CPU対戦では「あなたの負け」、2人対戦では「白の勝ち」 |
| 引き分け数 | 同数で終了した回数 |
| 勝率 | 勝ち ÷ (勝ち + 負け) × 100（引き分けを除いて計算） |
| 対戦履歴 | 日時・モード・結果・石数の一覧（最大100件） |

> **注意：** 戦績はブラウザの localStorage に保存されます。  
> 別のブラウザや端末では共有されません。  
> パスワードなどの個人情報は保存されません。

## 📱 スマートフォン対応

スマートフォンや小さい画面でも快適に遊べるよう調整しています。

- 盤面サイズが画面幅に応じて自動調整されます
- ゲーム画面のボタンが2列グリッドにまとまり、縦スクロールなしで操作できます
- モーダルの閉じるボタンが36×36pxの丸ボタンで、タップしやすい設計です
- 縦に余裕がある画面では、コンテンツが上下中央に自然に配置されます

## 🧪 自動テスト

[Playwright](https://playwright.dev/) による E2E テストを実装しています。  
Chromium・Firefox の2ブラウザで自動実行されます。

### テスト結果

```
110 passed / 0 failed（Chromium・Firefox の2ブラウザで実行）
```

### テスト対象

| テストグループ | 件数 | 内容 |
|--------------|------|------|
| モード選択画面 | 6件 | 画面表示・ボタン動作・レベル選択 |
| 2人対戦 - 基本動作 | 9件 | ゲーム開始・初期配置・ターン管理・石数表示 |
| CPU対戦 | 6件 | 各レベルの起動・CPU自動着手・思考中ロック |
| ボタン操作 | 3件 | リセット・モード選択に戻る |
| 戦績モーダル | 5件 | 開閉・サマリー表示・勝率表示 |
| 遊び方モーダル | 6件 | 開閉・セクション表示 |
| 設定モーダル | 11件 | 開閉・各設定の切り替え・localStorage への保存・ヒントOFF時の動作 |
| ゲーム終了 | 2件 | 勝敗表示・リセット後の初期化 |
| 効果音の呼び出しタイミング | 6件 | 開始・リセット・無効クリック時に音が鳴らないこと、着手時に鳴ること |

### テストの実行方法

```bash
# 1. 依存パッケージをインストール（初回のみ）
npm install

# 2. テスト用ブラウザをインストール（初回のみ）
npx playwright install

# 3. テストを実行
npm test

# 4. HTMLレポートをブラウザで確認（任意）
npx playwright show-report
```
