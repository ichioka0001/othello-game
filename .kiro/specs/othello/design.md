### 3.3 CPUアルゴリズム設計

#### 初級CPU（ランダム）
```
置ける場所の一覧を取得
→ ランダムに1つ選んで置く
```

#### 中級CPU（貪欲法）
```
置ける場所の一覧を取得
→ 各マスに置いたときにひっくり返せる石数を計算
→ 最も多くひっくり返せるマスを選ぶ
→ 同数の場合はランダムに選ぶ
```

#### 上級CPU（評価関数 + ミニマックス法）
```
評価関数で各マスに点数をつける
  - 角（4隅）: +100点（最も価値が高い）
  - 角の隣: -30点（角を取られやすくなる）
  - 辺: +10点
  - その他: ひっくり返せる石数 × 1点

ミニマックス法で数手先を読んで最善手を選ぶ
  - 探索深さ: 4〜6手（処理時間とのバランス）
  - アルファベータ枝刈りで高速化
```

## 7. Phase 6：ランク対戦・レート・マッチング 設計

### 7.1 レーティングシステム（Eloレーティング）

```
初期レート: 1500

レート変動の計算式:
  新レート = 現在のレート + K × (実際の結果 - 期待勝率)

  期待勝率 = 1 / (1 + 10^((相手レート - 自分レート) / 400))
  K係数 = 32（初心者）/ 16（中級者）/ 8（上級者）

例:
  自分のレート: 1500, 相手のレート: 1600
  期待勝率 = 1 / (1 + 10^(100/400)) ≈ 0.36
  勝利時の変動 = 32 × (1 - 0.36) ≈ +20
  敗北時の変動 = 32 × (0 - 0.36) ≈ -12
```

### 7.2 ランク区分

| ランク | レート範囲 |
|--------|----------|
| ブロンズ | 0〜1199 |
| シルバー | 1200〜1399 |
| ゴールド | 1400〜1599 |
| プラチナ | 1600〜1799 |
| ダイヤ | 1800〜1999 |
| マスター | 2000以上 |

### 7.3 マッチングキュー設計

```
マッチングキューへの追加
  → レート差 ±100 以内の相手を探す
  → 30秒待っても見つからない場合、許容範囲を ±200 に広げる
  → 60秒待っても見つからない場合、許容範囲を ±400 に広げる
  → マッチング成立 → ゲーム開始
```
